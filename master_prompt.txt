### 4. FUNCTIONAL REQUIREMENTS

Implement the following scheduling algorithms:

**A. First Come First Served (FCFS)**
- Non-preemptive scheduling.
- Processes execute according to arrival time.

**B. Highest Priority First (HPF)**
- Non-preemptive priority scheduling.
- Processes with higher priority execute first.
- Explicitly document the priority-number convention.

**C. Round Robin (RR)**
- Preemptive scheduling.
- Configurable time quantum.
- Processes receive CPU time in ready-queue order.
- Unfinished processes return to the ready queue.

**D. Shortest Remaining Time Next (SRTN)**
- Preemptive scheduling.
- The process with the shortest remaining burst time receives the CPU.
- Reevaluate scheduling when a new process arrives.

Handle idle CPU periods, simultaneous arrivals, completion events, and scheduling ties consistently.
